# Before Building Checklist

Before building or making major changes to the project, execute and verify all 20 of the following prerequisites:

1. **Create a PRD** (Product Requirements Document).
2. **Define the value proposition, pain, and ICP** (Ideal Contributor/Volunteer/Partner Profile).
3. **Export the PRD to Markdown**.
4. **Load the PRD into the coding agent**.
5. **Write/maintain AGENTS.md** as the single source of truth.
6. **Install appropriate coding-agent plugins/tools**.
7. **Connect GitHub** repository and ensure remote sync.
8. **Add a comprehensive .gitignore**.
9. **Generate a brand/design document** aligned with V-HELD's Ghanaian community identity.
10. **Lock in the technology stack** (Next.js, TypeScript, Tailwind, GSAP/Lenis, Turso, Cloudinary, Sentry).
11. **Set up a design system** with clear color palettes, spacing tokens, and typography.
12. **Break the PRD into concrete tasks**.
13. **Set up the database and authentication** (Turso DB, secure auth flows).
14. **Move secrets/API keys into environment variables** (`.env.local` / `.env.example`).
15. **Separate staging from production** environments.
16. **Add a thorough README.md**.
17. **Plan the folder/project structure** cleanly.
18. **Add error tracking** (e.g., Sentry).
19. **Explicitly define what will NOT be built** (scope boundaries).
20. **Commit small changes frequently** with descriptive commit messages.
