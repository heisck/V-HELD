PERFORMANCE IS A FIRST-CLASS FEATURE

Performance is NOT something to check at the end.

Build performance into the architecture from the beginning.

Use appropriate performance monitoring/profiling tools and dependencies.

Measure things such as:

* Lighthouse performance
* LCP
* CLS
* INP
* TTFB
* JavaScript execution
* bundle size
* memory usage
* WebGL rendering cost
* frame rate
* long tasks
* asset loading
* image sizes
* font loading
* animation performance

Use browser performance APIs where useful.

For 3D:

* monitor draw calls
* monitor geometries
* monitor textures
* monitor shader complexity
* avoid unnecessary objects
* use instancing where appropriate
* dispose of WebGL resources correctly
* pause expensive rendering when not visible
* use lower-quality rendering on weaker devices
* respect reduced-motion preferences

The website should feel extremely smooth.
